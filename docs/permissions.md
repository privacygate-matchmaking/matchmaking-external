# 역할과 API 경계

| 역할 코드 | 의미 | 이 저장소 권한 |
|---|---|---|
| member | 외부 회원 | 본인 제공 자료·증빙·동의 |
| counselor | 내부 상담 직원 | 파일 등록, 본인 반출 신청·조회 |
| approver | 반출 승인 담당자 | 신청 검토·승인·거절, 승인 철회 |
| data_admin | 데이터 관리자 | 내부 전체 회원 내보내기(내부 담당 범위) |

공통 패키지의 네 코드를 따릅니다. 알려진 역할이 둘 이상인 토큰은 모호한 권한으로 거부합니다. 상담 직원과 승인 담당자는 구분하며 자기 신청은 승인할 수 없습니다. 화면 메뉴와 무관하게 서버에서 검사합니다.

중계의 /api/internal/*는 URL 이름만으로 신뢰하지 않습니다. external-api 서비스 토큰과 회원 토큰 둘 다 검증합니다. 회원은 중계 파일 등록·반출 승인 API를 호출할 수 없습니다. 서비스 계정은 직원 역할이 아닙니다.
