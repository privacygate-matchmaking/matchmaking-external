# 매칭 업무 정책 — 현재 구현 기준

2026-11-13. 내부 상호 클릭·자동 동의 방식과 아직 통합하지 않은 외부 유료 방식이다. 최종 정책은 월요일 협의 후 바꿀 수 있다. [차이·논의 항목](internal-handoff.md)을 함께 확인한다. 가격은 프로젝트 시험값이며 실제 결제 연동을 뜻하지 않는다.

## 유지할 경계

- 내부 저장소의 코드·README는 수정하지 않는다.
- 외부 브라우저는 external-api를 거쳐 transfer-api만 호출한다.
- 직원별 담당 회원 검사는 내부의 현재 권한·담당 관계가 기준이다. 원본·심사 결과를 임의로 외부에 복사하지 않는다.
- 기존 소개 자료의 승인 ID·파일·버전·해시·수신자 검사와 제한된 baseline 비교를 유지한다.
- 변경 사항은 로컬에서 검증하며 GitHub push 전 사용자 확인을 받는다.

## 합의된 업무 정책

| 항목 | 정책 |
|---|---|
| 상품 | 이음 정회원, 3,300,000원(VAT 포함), 6개월, 매칭권 5개 |
| 결제 | 실제 금전 거래가 없는 시험 결제만. 실제 PG 연동을 완료했다고 표시하지 않음 |
| 신청 | 유효한 회원·유료 자격·남은 매칭권 필요 |
| 제한 | 한국 날짜 기준 하루 신규 신청 3건, 동시 대기 3건 |
| 매칭권 | 신청 시 예약, 수락 시 사용 확정, 거절·72시간 무응답·수락 전 취소 시 예약 해제 |
| 중복·재신청 | 같은 상대의 대기·매칭 중 중복 금지, 거절 후 30일 재신청 제한 |
| 수신 | 무료회원도 받은 신청에 응답할 수 있으나 본인 계정에서만 가능 |
| 종료 | 상호 매칭 종료 후 향후 공개 중단, 사용한 매칭권 자동 반환 없음 |
| 취소 벌점 | 변심·일정 변경·취소에 추가 횟수 차감/취소 수수료 없음. 성사 때 사용한 1회 유지와 구분 |
| 동의 | 정보 소유자가 상대·항목·기한을 지정. 상호 수락만으로 자료 공개하지 않음 |
| 개인정보 | 원본 증빙은 공개하지 않고, 검토 결과·승인된 공개본만 제공 |

## 추가 결정 결과

1. 매칭·이용권·방향별 공개 동의는 중계 DB의 별도 `matching_*` 테이블에서 관리한다. 외부 세션 SQLite와 분리한다. 내부는 회원·담당·검토 결과의 기준 데이터를 제공한다.
2. 이번 범위는 매칭 기능과 검토·마스킹 결과 연동 계약·화면까지다. 원본 AI/OCR 분석 서비스는 만들지 않는다. 원본의 진위 자동 판별을 구현했다고 표현하지 않는다.

기존 저장소를 변경하지 않고 외부 저장소의 추가 Compose와 마이그레이션으로 구성한다. 실제 연동과 명시적으로 켜는 합성 실습 모드를 구분한다.

## 검증할 결과

- 타인 신청에 대한 수락·거절·취소·종료 불가.
- 무료·기간 만료·매칭권 소진 회원의 발신 제한.
- 동시 요청·중복 결제 확인·반복 응답에도 매칭권 초과 사용·중복 지급 불가.
- 매칭·동의가 없는 상대의 상세 정보 미반환.
- API·서버 오류가 회원 세션 만료로 잘못 처리되지 않음.
- 기존 로그인·반출 비교·정상 다운로드 시험 유지.
