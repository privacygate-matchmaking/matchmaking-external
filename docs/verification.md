| 정상 업무 | 파일 등록→신청→독립 승인→회원 목록→실제 파일 바이트 |

| 세션 | PKCE·state·브라우저 결합·재사용 거부·갱신·암호화 저장·재시작·만료·로그아웃 |

업무 흐름 시험은 FastAPI TestClient, 내부 HTTP 응답 대역, 명시적 SQLite 시험 어댑터를 사용합니다. 운영 코드는 PostgreSQL만 허용합니다. 위 결과를 PostgreSQL 동시성 또는 실제 Keycloak 통합 결과로 해석하지 않습니다.

남은 실제 환경 확인:

1. 내부 담당자의 업무 API 구현과 실제 제공 동의·회원 관계 확인.
2. Docker 이미지 빌드·볼륨 권한·PostgreSQL 스키마/트랜잭션 확인.
3. 실제 Keycloak 로그인·갱신·로그아웃과 브라우저 UI 확인.
4. 내부 내보내기 파일을 사설 중계에 등록하는 전체 공격 연결 및 정상 업무 유지 확인.
5. Wazuh 수집·반복 접근/승인 불일치 경보 확인. API 403과 경보는 별도 평가.

초기 에이전트 작업 환경에서는 Docker 엔진 named pipe 접근이 거부되었습니다. 이후 사용자가 PC에서 직접 실행한 출력으로 전체 컨테이너 기동, 두 DB healthy, 앱 계정과 users 4건·members 8건, Keycloak 설정 Exited(0)을 확인했습니다. 외부 첫 화면은 사용자가 제공한 브라우저 사진으로 확인했습니다. 실제 PostgreSQL 업무 트랜잭션·로그인·전체 연동·Wazuh 경보는 아직 검증 전입니다. Wazuh 설치·규칙도 이 변경에 포함하지 않습니다.
