## 자동 시험

2026-11-14 두 방향 수정 후: 외부·관제·새 내부 HTTP 계약을 함께 실행해 **Python 142개 통과**, Node 화면 시험 9개 통과. 내부 화면 HTML/스크립트 참조와 양쪽 Python/JavaScript 구문도 검사했습니다. 내부 시험은 SQLite 어댑터·토큰 검증 제공자 대역이며 실제 PostgreSQL/Keycloak 시험이 아닙니다.

이전 확인 기록:

- 일정 조율 추가 후 Python 109개, Node 화면 제어 9개 통과.
- 이후 순차 smoke·실패 진단 수정에 대해 관제 도구 21개를 별도로 재실행해 통과. 앞 숫자와 합산하지 않습니다.
- 기본·회원 상태 활성화·합성 실습 Compose 병합 3종, JavaScript 구문과 HTML 참조 확인.
- 범위: 실제 RSA 검증·세션/갱신·CSRF/Origin·파일/승인/동의·baseline/enforce·유료 횟수/중복/동시 요청·회원 상태·일정 소유권/담당 의견 보호.
- 업무 API에는 내부 응답 대역, DB에는 명시적 SQLite 시험 어댑터를 사용합니다. 실제 PostgreSQL 부하·내부 DB 전체 업무 시험의 대체가 아닙니다.

```sh
python -m pytest tests/integration tests/observability
node --test tests/frontend/account.test.cjs tests/frontend/meetings.test.cjs
```

시험 의존성은 실행 가이드에 따라 설치해야 합니다.

## 아직 확인하지 않은 것

- 최신 내부 업무 DB·새 20명 시드에서 증빙 승인→매칭→동의→정상 반출 전체 연결.
- 유료 방식으로 내부 후보·검토 결과 API 코드는 연결했고 구 상호 매칭 경로는 409로 종료했습니다. 새 내부 데이터에서 실제 연결·전환 검증은 남아 있습니다.
- 직원 일정 BFF·현재 담당 관계 확인 API·직원 화면 코드는 연결했습니다. 실제 브라우저·직원/회원 왕복 검증은 남아 있습니다.
- 연락처 최종 승인 전달, AI/OCR·마스킹 엔진, 챗봇, 실제 결제. 현재 미구현입니다.
- 두 핵심 비교 시나리오의 실제 요청·응답·파일을 갖춘 최종 연속 시연.
- 모든 계정·직원 역할 변경의 즉시 반영 및 Mac 전체 실행.
- 일괄·동시 입력의 반복 경보 신뢰성. 일괄 시험에서 100112 누락을 관찰했고 3초 간격은 통과했습니다.

실제 차단은 API 응답·파일 미반환으로, 탐지는 Wazuh 기록으로 별도 검증합니다. 합성 smoke 통과만으로 공격 방어 전체가 완성됐다고 표시하지 않습니다. 미구현 API를 성공 응답이나 합성 결과로 자동 대체하지 않습니다.
